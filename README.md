# 打合せタスク逆算

打合せ日と工程の節目（着工・上棟・引渡し）を入れると、自社の段取りルールから「いつまでに・誰が・何をするか」を並べるツールです。
木住協「生成AI活用 実践研修」工務パートのサンプルです。

- 公開: https://takeda-png.github.io/uchiawase-tasks/
- 打合せが発注に間に合わない日程だと警告します（例：内装・設備打合せは上棟の28日前まで）
- 担当で絞り込み、完了の印をつけられます（このブラウザに保存）
- カレンダー用ファイル（.ics）・CSV・印刷、2週間分の連絡文コピー（Chatwork・LINEに貼る用）
- 段取りルールは画面で編集でき、CSVで保存・読み込みできます
- 計算はすべてブラウザの中で行い、入力内容は外部に送信しません

工程の日付は「工程表メーカー」で出せます: https://takeda-png.github.io/koutei-maker/

## Chatwork・スプレッドシート連携

ページから直接Chatworkには送れないため、Googleスプレッドシートに付けた Apps Script（`apps-script.gs`）を中継役にします。ChatworkのAPIトークンは Apps Script のスクリプト プロパティに保存し、ページには置きません。設定手順はページ下の「Chatwork・スプレッドシート連携の設定」にあります。設定は2つのツールで共有されます。
- 「やること」シートに書き出した案件は、`毎朝の通知を設定する` を実行すると、期限が7日以内・過ぎた未完了の分を毎朝8時台にChatworkへ送ります
